## Getting Help

1. If you **encounter any issues or have questions or comments**, please use the help feature to generate an email with your error log attached.

2. If you are having trouble with the help button, email us at [nlh-team.npe@nikonglobal.onmicrosoft.com](mailto:nlh-team.npe@nikonglobal.onmicrosoft.com) and attach your error log if possible.

   **Your error log will be located in the directory where you installed the program as the file `NikonLogHandlerError.log`.**

   **IMPORTANT:** Do not upload any NSR logs or Nikon confidential items (like images) with your email. Put them in a shared folder and add a link to the issue.

### Adding New Handler

If you wish to add a new log handler, please read the [Add New Handler Guide]( http://npe-apgit01.nikonoa.net/NPE-ES-Hardware/Nikon_Log_Handler/wiki/Making-a-New-Handler ) for all the information.
