# NLH Scripts – Nikon Precision Inc. (NPI)

> **Nikon Confidential – Internal Use Only**

This folder contains NPI-specific NLH parser scripts and local documentation.

## Folder Structure

```
scripts/    Parser scripts (.py or .pyenc)
docs/       Documentation for each parser (PDF / DOCX)
```

## SharePoint Source

Scripts are downloaded from:  
`https://nikonprecision.sharepoint.com/sites/NPI-Engineering/Nikon Log Handler/Scripts/`

Use `tools/script_downloader.py --subsidiary NPI` to sync the latest scripts.
