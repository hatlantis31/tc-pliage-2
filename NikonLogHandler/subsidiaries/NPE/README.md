# NLH Scripts – Nikon Precision Europe (NPE)

> **Nikon Confidential – Internal Use Only**

This folder contains NPE-specific NLH parser scripts and local documentation.

## Folder Structure

```
scripts/    Parser scripts (.py or .pyenc)
docs/       Documentation for each parser (PDF / DOCX)
```

## SharePoint Source

Scripts are downloaded from:  
`https://nikonglobaleu.sharepoint.com/sites/NPE-ESHardware/Nikon Log Handler/Scripts/`

Use `tools/script_downloader.py --subsidiary NPE` to sync the latest scripts.
