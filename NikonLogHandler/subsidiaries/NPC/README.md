# NLH Scripts – Nikon Precision Corporation (NPC)

> **Nikon Confidential – Internal Use Only**

This folder contains NPC-specific NLH parser scripts and local documentation.

## Folder Structure

```
scripts/    Parser scripts (.py or .pyenc)
docs/       Documentation for each parser (PDF / DOCX)
```
